## 📁 Proyectos Destacados

### 1. 👥 [HR Analytics: Control de Gestión de Talento y Clima Laboral](./01-HR-Analytics-Dashboard)
- **Herramienta:** Power BI Desktop | DAX | Power Query
- **Descripción:** Análisis de la rotación de personal (1.470 empleados), impacto de horas extras y clima laboral para la toma de decisiones en Recursos Humanos.
- **Puntos Clave:** Creación de diccionario de datos técnico, modelo relacional desde cero y métricas DAX de rotación y satisfacción.
- 🔗 **[Ver proyecto completo y documentación ➔](./01-HR-Analytics-Dashboard)**

### 2. 💰 [Panel de Finanzas Personales y Control Presupuestario](./02-Personal-Finance-Dashboard)
- **Herramienta:** Power BI Desktop | DAX | Power Query
- **Descripción:** Control de salud financiera personal que analiza fuentes de ingresos, estructura de gastos por categorías y flujo de caja mensual para optimizar el cumplimiento de metas de ahorro.
- **Puntos Clave:** Análisis de variaciones mensuales (déficit/superávit), segmentación de ingresos/egresos y métricas DAX de cumplimiento de metas y saldo disponible.
- 🔗 **[Ver proyecto completo y documentación ➔](./02-Personal-Finance-Dashboard)**
